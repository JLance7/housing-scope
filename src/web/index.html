About HomeScope and its data

HomeScope is a personal project that demonstrates listing imports, budgeting, and alert delivery. Online listings show when HomeScope last checked them. Sample listings are labeled.

Ownership estimates include the mortgage payment and any taxes, insurance, or HOA fees supplied with the listing.
